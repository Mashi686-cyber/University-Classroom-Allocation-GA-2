# Final Cleanup Check

This document outlines files and directories that should be excluded from the final project submission ZIP file to maintain a clean and professional academic repository.

## REMOVE BEFORE ZIP
These items are generated at runtime, are excessively large, or contain local system dependencies:

- `.venv/` (Python virtual environment dependencies)
- `web/frontend/node_modules/` (Node.js dependencies)
- `web/frontend/.next/` (Next.js build cache)
- `__pycache__/` directories (Python bytecode)
- `.pytest_cache/` (Pytest run cache)
- `results/web_runs/` (Unless a specific UI run needs to be demonstrated directly from disk. Generally, UI runs are generated by the user dynamically)
- Any temporary scratch scripts or debug logs in the root directory.

## KEEP
These items are essential for the evaluator to run and verify the project:

- `src/` (All core algorithms and evaluation logic)
- `tests/` (Test suite)
- `data/generated/` (The generated datasets for Small, Medium, and Large scenarios)
- `results/experiments/` (Phase 5 parameter sensitivity data)
- `results/comparison/` (Phase 6 baseline vs GA data)
- `web/` (Frontend and backend source code, `package.json`, `requirements.txt`)
- `docs/` (All academic audit and reporting documents)
- `start.py`, `start.sh`, `start.bat`, `start.ps1` (Cross-platform launchers)
- `README.md` and `requirements.txt`

## OPTIONAL
- `results/web_runs/*.json` (Could be kept if you want the dashboard to immediately display history on first load before the user executes a run)
